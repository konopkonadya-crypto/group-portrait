ГРУППОВЫЕ ПОРТРЕТЫ — установка
==============================

САМЫЙ ПРОСТОЙ СПОСОБ (один файл)
--------------------------------
1. Распакуйте архив в папку без русских букв, например C:\GroupPortrait
2. Дважды щёлкните setup.bat
3. Ждите 15-30 минут, ничего не закрывайте
4. Программа появится в папке dist\GroupPortrait\GroupPortrait.exe

setup.bat делает всё сам:
  - находит Python 3.15 (или скачивает и ставит его)
  - ставит библиотеки
  - собирает GroupPortrait.exe
  - сам открывает папку с готовой программой

Интернет нужен только во время установки. Потом программа работает без него.
Python, если его не было, останется в системе — это нормально.


ЕСЛИ НУЖЕН ФАЙЛ SETUP.EXE
-------------------------
Такой файл собирается на серверах GitHub (на Windows) за 15 минут:
1. Создайте бесплатный аккаунт на github.com
2. Создайте приватный репозиторий и загрузите туда папку GroupPortrait целиком
   (важно: вместе со скрытой папкой .github)
3. Откройте вкладку Actions, выберите "Build Windows", нажмите Run workflow
4. Дождитесь зелёной галочки и скачайте артефакт GroupPortrait-setup
5. Внутри будет GroupPortrait-Setup.exe — обычный установщик

Этот способ я не мог проверить, поэтому если сборка упадёт —
пришлите последние строки ошибки из журнала.


ЧАСТЫЕ ПРОБЛЕМЫ
---------------
"Python not found" и скачивание не идёт
   Нет интернета или мешает антивирус. Отключите антивирус, запустите setup.bat снова.

Красные строки при установке библиотек
   Обычно интернет или антивирус. Проверьте соединение, повторите.

Windows пишет "Система Windows защитила ваш компьютер"
   Нажмите "Подробнее" -> "Выполнить в любом случае".
   Так бывает у любых новых программ без подписи.

Антивирус удалил GroupPortrait.exe
   Ложное срабатывание. Добавьте папку dist\GroupPortrait в исключения.

Окно мигает и закрывается
   Запустите setup.bat ещё раз и посмотрите, на каком шаге остановилось.
   Пришлите текст с экрана.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Каталог серий и миниатюры:  %APPDATA%\GroupPortrait
Сами снимки остаются там, где вы их держите.
